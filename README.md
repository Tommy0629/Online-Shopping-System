# Online Shopping System

## What the program does
This program is an online shopping system. It lets the user:
- browse the list of products
- add products to a shopping cart
- remove products or change quantities
- view the cart and see the total price
- check out and place an order

The program uses classes to store the products, the shopping cart,
and the customer's order.

## How to run it
1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run the main file:

```bash
python3 demo.py
